# floorball4all-data-overview

Ein kleines Daten-Overview-Projekt für Floorball4all.

## Dateien

- `index.html` - Hauptseite
- `compare.html` - Vergleichsansicht
- `compare.js` - JavaScript für Vergleichsinhalte
- `dashboard.html` - Dashboard mit Kennzahlen
- `dashboard.js` - JavaScript für das Dashboard
- `data.js` - Datenladen, Cache und CSV-Export
- `script.js` - JavaScript für Weltkarte und Admin-Bereich
- `style.css` - Seitenstil

## Verwendung

1. Öffne `index.html` im Browser.
2. Nutze die vorhandenen Seiten für Datenvergleich und Darstellung.

## Hinweise

Die Daten werden aus dem Google Sheet geladen und lokal kurz zwischengespeichert.
